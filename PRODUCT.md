# Product

## Register

product

## Users

A small household group (the owner plus invited members) tracking prepaid
subscriptions, shared finances, and a booking calendar. They check in a few
times a week from a desktop browser, usually mid-task: "are we burning this
package fast enough", "what did we spend this month", "book Thursday's class".
Sessions are short and goal-directed; the interface must answer at a glance.

## Product Purpose

yoka tracks burndown of prepaid packages (yoga classes, coaching hours),
a monthly finance ledger, and the calendar of usage events. Success is a
user who can read pace, spend, and schedule in seconds and record a usage
or expense in under half a minute.

## Brand Personality

Precise, calm, quick. The tool disappears into the task: no ornament, no
ceremony, information density with breathing room. Category reference is
Linear: crisp hairlines, compact controls, one sans family, restrained
motion that only conveys state.

## Anti-references

- Warm "editorial paper" styling (beige washes, tan hairlines, serif
  display headings). This was the previous system and is retired.
- SaaS dashboard clichés: hero metrics with gradient accents, identical
  icon-card grids, glassmorphism.
- Navy or any second brand hue. The brand is green on white, only.
- Italic text anywhere in the UI.

## Design Principles

- Density earns trust: compact rows, tabular numerals, aligned columns.
- One accent, spent deliberately: green marks the primary action, the
  current selection, and live state, never decoration.
- Status reads without color: every status has a glyph as well as a hue.
- Motion is feedback: 100–200 ms ease-out on state change, nothing
  orchestrated, honors reduced motion.
- Consistency over surprise: the same control vocabulary on every screen.

## Accessibility & Inclusion

Body/secondary text meets WCAG AA on white. Status is never encoded by
color alone (glyph marks in pills and dots). `prefers-reduced-motion`
collapses all animation. Focus is always visible via the accent outline.
